# the-patch-next

The website for [The Collabage Patch](https://thecollabagepatch.com): Next.js 14 with a
custom Express + socket.io server (`server.js`) that also runs the audiovisual radio.

- **Developing and deploying:** [DEVELOPMENT.md](DEVELOPMENT.md)
- **Server setup (nginx, static pages, status service):** [infra/README.md](infra/README.md)

```bash
npm ci
npm run dev   # http://localhost:3000
```
